## Documented browser diagnostic

The installed WebKit emits an inline stylesheet CSP warning for each parsed native select. A minimal page with strict CSP, one select and **no application scripts** reproduces the warning (`native-select.spec.cjs`). This is isolated from production script behavior; the harness pairs the exact message with a style CSP violation at the actual select source line and records it in diagnostics. It does not globally ignore CSP errors or change production CSP. Recheck this allowance on browser upgrades; the native reproduction intentionally fails if the behavior changes so the allowance can be removed.
